# weekly-review

## Procedure

1. Read `metrics.csv` for all three products, last 7 days and last 28 days.
   Run `gd metrics` and `gd streak` rather than reading the CSV by hand.
2. Report the four numbers per product. Replies, qualified conversations,
   attributed signups, paid.
3. Name the single best move of the week and say precisely why it worked.
   Trace it to a rule in `learnings.md` if one exists, or propose a new one.
4. Name the worst channel. Recommend burning it or changing the approach.
5. Report the streak. Weekdays in the last 14 with at least one move sent.
6. List every claim in each `icp.md` still tagged `assumed` that is now
   testable, with the specific test and the cheapest way to run it.
7. Flag any Echoself move from the week that came close to the ethics line.

## Output

A short written brief. No slides. No dashboard. Lead with the worst number.

## Hard rules

- **Lead with the number that looks worst.** No burying.
- If the streak is under 7 of 14, say plainly that the system is failing,
  regardless of how the other numbers look.
- At day 30, evaluate the kill criterion in `docs/PRD.md` section 11 and state
  the recommendation without softening it.
- Never report page views, impressions, or reach.
