# Deckle ethics gate

`daily-moves` reads this before generating anything.

## never_post

- **Stack Overflow answers.** Product links in answers violate site policy and
  will get the account removed. Answer the question with code only, or do not
  answer. This is absolute.
- Any GitHub issue on a competitor's repository. Answering a question about
  Puppeteer with a pitch for Deckle in Puppeteer's own issue tracker is
  bad behavior and reads as such.

## no_first_person_promo

- `r/programming`
- `r/experienceddevs`

Helpful answers with code. No link, no product name.

## open

- `r/webdev`
- `r/node`
- `r/django`
- `r/rails`
- `r/laravel`
- Hacker News, Show HN only, and only for something genuinely new
- dev.to and the owned blog
- Owned docs and comparison pages

## Standing rules

1. If Puppeteer is the right answer for their case, say so plainly.
2. No benchmark claim without a benchmark Fred ran.
3. Never post the same answer text in two communities. Rewrite it.
4. One Show HN. Not a series.
