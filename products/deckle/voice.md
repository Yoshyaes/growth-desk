# Deckle voice

Register. Terse. Show the code. No adjectives. Benchmarks over claims.
Engineers can smell marketing copy and they punish it.

Read `shared/voice-rules.md` first. It governs.

## Sentences that sound right

- [verified, from the site] "HTML in. Pixel-perfect PDFs out."
- [verified, from the site] "Generate invoices, reports, and certificates from
  HTML, React, or templates. One API call, milliseconds."
- [seed] "You are maintaining a headless Chrome in production. You do not have to."
- [seed] "Free tier is a thousand PDFs a month with every feature. Not a trial."
- [seed] "Self-hostable Docker image if you cannot send documents off your infra."

## Rules for technical rooms

- Lead with the code block, not the pitch.
- Answer the actual question completely before mentioning Deckle at all.
- Never post a product link inside a Stack Overflow answer. That is against
  policy and it will get the account removed.
- If Puppeteer is the right answer for their case, say so.
